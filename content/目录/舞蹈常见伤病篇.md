# 舞蹈常见伤病

舞蹈伤病的核心逻辑不是“随机发生”，而是：

> **控制系统失衡 → 结构过载 → 局部受伤**

| 部位 | 实际内容 |
| --- | --- |
| 肩 | [[肩峰下撞击综合征（Subacromial Impingement Syndrome，SAIS）]] |
| 腰 | [[棘间韧带炎（Interspinous Ligament Injury）]]<br>[[椎弓峡部裂（Lumbar Spondylolysis）]]<br>[[腰椎小关节疼痛（Lumbar Facet Joint Pain）]]<br>[[腰椎管狭窄症（Lumbar Spinal Stenosis）]]<br>[[腰椎间盘突出（Lumbar Disc Herniation）]]<br>[[腰肌劳损]]<br>[[转开与损伤关系]] |
| 膝盖 | [[半月板损伤（Meniscus Injury）]]<br>[[滑膜炎（Synovitis）]]<br>[[膝关节积液（Knee Effusion）]]<br>[[髌下脂肪垫炎和膝关节积液区分]]<br>[[髌下脂肪垫炎（Infrapatellar Fat Pad Syndrome）]]<br>[[髌股疼痛综合征（PFPS）]]<br>[[髌骨脱位（Patellar Dislocation）]] |
| 踝 | [[ATFL（前距腓韧带）损伤]]<br>[[Sever病（Sever's Disease，跟骨骨骺炎）]]<br>[[副舟骨综合征（Accessory Navicular Syndrome）]]<br>[[功能性不稳（Functional Ankle Instability）]]<br>[[后胫肌功能不全（PTTD）]]<br>[[后胫肌腱炎（Posterior Tibial Tendinopathy）]]<br>[[腓骨头功能障碍（Fibular Head Dysfunction）]]<br>[[足底筋膜炎（Plantar Fasciitis）]]<br>[[足舟骨疼痛（Navicular Pain）]]<br>[[跖骨应力性骨折（Metatarsal Stress Fracture）]]<br>[[跖骨痛（Metatarsalgia）]]<br>[[跟腱炎（Achilles Tendinopathy）]]<br>[[踝关节扭伤（Ankle Sprain）]]<br>[[过度柔韧导致不稳]] |
| 髋与骨盆 | [[梨状肌综合征（Piriformis Syndrome）]]<br>[[骶髂关节疼痛（Sacroiliac Joint Pain，SIJ Pain）]]<br>[[髋撞击综合征（FAI）]] |
| 风湿免疫疾病 | [[强直性脊柱炎（Ankylosing Spondylitis，AS）]]<br>[[类风湿关节炎（Rheumatoid Arthritis，RA）]]<br>[[骨关节炎（Osteoarthritis，OA）]] |
