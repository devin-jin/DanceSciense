对于舞者、普拉提和康复训练来说，**核心（Core）和呼吸（Breathing）本质上是同一个系统的两面**。

很多人把核心理解成腹肌，但现代运动科学认为：

> 核心首先是一个“压力管理系统（Pressure System）”，其次才是力量系统。

---

# 核心的真正组成

经典的核心稳定模型（Panjabi、Hodges等学者）认为：

核心像一个圆柱体：

```
        膈肌
          ↑

腹横肌 ← 核心 → 多裂肌

          ↓
       盆底肌
```

四个关键结构：

- 膈肌（Diaphragm）
    
- 腹横肌（Transversus Abdominis）
    
- 多裂肌（Multifidus）
    
- 盆底肌（Pelvic Floor）
    

共同形成：

**腹内压（Intra-Abdominal Pressure, IAP）**

---

# 呼吸为什么影响核心？

当你吸气时：

膈肌下降

```
      ↓
    膈肌

   腹腔压力↑

盆底肌被动下降
```

腹腔像气球一样膨胀。

此时：

- 腹横肌离心控制
    
- 盆底肌协同下降
    

形成稳定的压力环境。

---

# 什么是好的核心启动？

很多人做平板支撑时：

```
收腹
憋气
肚子拼命往里吸
```

实际上这并不是理想状态。

真正的核心稳定应该是：

```
吸气
↓
腹腔360°扩张

呼气
↓
腹横肌参与收缩

保持压力
↓
完成动作
```

所以：

> 核心稳定 ≠ 拼命收腹
> 
> 核心稳定 = 呼吸下维持腹内压

---

# 为什么舞者容易出现核心问题？

舞蹈训练常见习惯：

### 1. 吸肚子

老师常说：

- 收腹
    
- 提气
    
- 拉长
    

很多学生变成：

```
一直吸肚子
```

结果：

- 膈肌活动受限
    
- 呼吸变浅
    
- 核心反而不稳定
    

---

### 2. [[肋骨外翻]]

常见于：

- 下腰
    
- Arabesque
    
- Penché
    

表现：

```
胸廓前顶
肋骨外翻
腰椎代偿
```

此时核心失去压力管理能力。

---

### 3. 用腰代替核心

例如：

Developpé

本该：

```
髋屈肌发力
核心稳定
```

结果：

```
腰椎前凸增加
肋骨抬起
```

看似腿抬高了，

实际上是腰椎代偿。

---

# 普拉提为什么那么强调呼吸？

普拉提创始人 Joseph Pilates 有一句经典的话：

> Breathing is the first act of life and the last.

普拉提中的呼吸不是放松用的。

而是：

**利用呼吸建立核心控制。**

例如：

Hundred

Roll Up

Single Leg Stretch

都要求：

```
呼吸
+
核心控制
+
动作控制
```

同步完成。

---

# 舞者最需要的呼吸方式

## 横膈膜呼吸（Diaphragmatic Breathing）

吸气时：

```
前
侧
后

360°扩张
```

而不是：

```
耸肩
抬胸
```

---

## 360度呼吸

理想状态：

```
前腹扩张
侧腰扩张
后腰扩张
```

很多舞者只有：

```
前面鼓起来
```

实际上后侧扩张能力更重要。

---

# 呼吸如何影响下腰？

很多舞者下腰时：

```
先憋气
↓
腰椎顶出去
↓
完成下腰
```

短期看更容易下去。

长期：

- 腰椎压力增加
    
- 椎间关节压缩
    
- 代偿加重
    

更好的方式：

```
吸气建立腹内压

呼气控制肋骨

保持压力

进入后伸
```

这也是：

- Bridge Hold
    
- Segmental Spine Control
    
- Pilates Swan
    

强调呼吸控制的原因。

---

# 呼吸如何影响外开（Turnout）？

很多舞者不知道：

外开其实需要核心稳定。

如果核心失稳：

```
骨盆旋转
↓
腰椎旋转
↓
假外开
```

真正的外开应该：

```
呼吸建立稳定

骨盆固定

深层外旋肌工作

完成Turnout
```

所以：

Turnout训练前做几组呼吸训练，往往能立刻改善动作质量。

---

# 最适合舞者的呼吸训练

### 1. 鳄鱼呼吸（Crocodile Breathing）

俯卧位

双手放额头

感受：

```
后腰扩张
肋骨扩张
```

5分钟

---

### 2. 90/90呼吸

仰卧

髋膝90°

脚踩墙

吸气：

肋骨扩张

呼气：

肋骨回收

5组×5次

---

### 3. Bear Plank呼吸

熊爬支撑位

保持：

```
脊柱中立
肋骨稳定
正常呼吸
```

3组×20秒

---

### 4. Dead Bug呼吸

呼气伸腿

吸气回位

训练：

- 核心稳定
    
- 髋部控制
    
- 呼吸协调
    

---

# 对舞者最重要的一句话

很多人认为：

> 核心是腹肌力量。

实际上对于舞者而言：

> 核心首先是呼吸控制能力。

如果呼吸模式错误，即使卷腹能做100个，也可能在：

- Developpé
    
- Arabesque
    
- Penché
    
- Backbend
    

中出现骨盆失控和腰椎代偿。

而一个能够在动作中保持**360°呼吸 + 腹内压稳定**的舞者，即使绝对力量不大，往往也会表现出更好的平衡、外开控制和下腰质量。
